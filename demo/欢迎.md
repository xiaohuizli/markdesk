# 快速开始

MarkDesk 是本地 Markdown 文档工作台，提供阅读、文件导航和全文搜索。

## 打开文档

在左侧文件树中选择文档。点击顶部搜索图标，可以搜索当前文件夹中的内容。

## 搜索

- 输入 `搜索`，查找不同文件中的相关段落。
- 输入 `REA_CHAIN`，验证搜索结果和原文定位。
- 使用输入框右侧的选项，切换大小写、全词或正则匹配。
- 点击结果中的匹配行，打开文档并定位到相应位置。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 跨文件搜索 | ⇧⌘F |
| 文内查找 | ⌘F |
| 快速打开 | ⇧⌘O |
| 源代码模式 | ⌘/ |

点击左下角文件夹名称可以打开其他文件夹、刷新列表或导出搜索记录。
